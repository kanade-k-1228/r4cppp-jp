## その他の読み物

- [Rust book/guide](http://doc.rust-lang.org/book/) - Rust の学習に最適な公式ドキュメント。このチュートリアルでカバーしていない内容や、別の視点での説明が必要な場合はこちらを参照してください。
- [Rust API ドキュメント](http://doc.rust-lang.org/std/index.html) - Rust 標準ライブラリの詳細なドキュメント。
- [Rust リファレンスマニュアル](https://doc.rust-lang.org/reference/) - 一部古い情報もありますが、言語仕様の詳細を調べるのに役立ちます。
- [Discuss フォーラム](http://users.rust-lang.org/) - Rust の使い方や学習について議論・質問できるコミュニティフォーラム。
- [StackOverflow Rust の質問](https://stackoverflow.com/questions/tagged/rust) - 初心者から上級者まで、多くの Rust 関連の質問と回答があります。ただし、Rust は長年の間に大きく変化しているため、古い回答には注意が必要です。
- [A Firehose of Rust](https://www.youtube.com/watch?v=IPmRDS0OSxM) - C++プログラマー向けに、Rust のライフタイム、可変エイリアシング、ムーブセマンティクスを解説した講演動画。
